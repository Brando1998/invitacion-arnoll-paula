# invitacion-arnoll-paula

Invitación de boda web para Arnoll y Paula. Vue 3 + Vite.

## Antes de publicar

Edita **`src/data/wedding.js`**: ahí están todos los datos marcados con `[placeholder]`
que hay que reemplazar (fecha de la ceremonia/recepción, lugares, direcciones, código
de vestimenta, notas, link de videollamada si aplica, ideas de regalo).

Las fotos están en `src/assets/images/` (`hero.jpg`, `sidebar-bg.jpg`, `gallery-1.jpg`
a `gallery-5.jpg`). Para agregar más fotos a la galería, cópialas ahí e impórtalas en
`src/components/Gallery.vue`.

## Desarrollo

```sh
npm install
npm run dev
```

## Build de producción

```sh
npm run build
```

## Lint y formato

```sh
npm run lint
npm run format
```
